CẮT NHANH: kéo thả video, tự bỏ khoảng lặng

Kéo video thả lên một file là xong: các đoạn im lặng được cắt bỏ, ra video mới gọn hơn. File gốc giữ nguyên.

Bước ANhận file trong nhóm Zalo

  1. Vào nhóm Zalo ĐẠI LÊ AI

    Bấm nút Vào nhóm Zalo nhận file ở trang này, rồi bấm Tham gia nhóm. Nhóm miễn phí.

  2. Mở kho file của nhóm

    Trên máy tính (Zalo PC): trong nhóm, nhìn cột bên phải, mục Ảnh/Video, File, Link, bấm File.
    Trên điện thoại: trong nhóm, bấm biểu tượng ☰ ở góc trên bên phải, chọn Ảnh, file, link, rồi chọn thẻ File.
    File cũng được ghim ở đầu nhóm, bấm vào tin ghim là thấy.

  3. Tải file CatNhanh-DaiLeAI.zip

    Bấm vào file rồi chọn Tải về. Công cụ chạy trên máy tính Windows, nên hãy tải trên Zalo máy tính. Lỡ nhận trên điện thoại thì bấm giữ file, chọn Chia sẻ rồi gửi vào Cloud của tôi, sau đó mở Zalo trên máy tính để tải.

  4. Tìm file vừa tải

    File thường nằm trong thư mục Downloads (Tải xuống), hoặc thư mục Zalo Received Files trong Tài liệu (Documents).

Bước BMở và dùng CẮT NHANH

  1. Giải nén file

    Bấm chuột phải vào CatNhanh-DaiLeAI.zip, chọn Extract All (Giải nén tất cả). Bạn sẽ có thư mục CatNhanh-DaiLeAI, bên trong có file CatNhanh.bat.

  2. Cài Python và ffmpeg (chỉ làm 1 lần)

    Bấm phím Windows, gõ PowerShell, mở lên. Dán lần lượt 2 dòng dưới, mỗi dòng bấm Enter và đợi chạy xong:winget install Python.Python.3.12winget install Gyan.FFmpegCài xong thì đóng PowerShell và khởi động lại máy một lần.

  3. Kéo video thả lên CatNhanh.bat

    Mở thư mục chứa video, kéo file video (một hoặc nhiều file) thả thẳng lên biểu tượng CatNhanh.bat. Cửa sổ đen hiện lên và tự chạy. Nếu Windows hỏi "Windows protected your PC", bấm More info rồi Run anyway.

  4. Lấy video đã cắt

    Video mới nằm ngay cạnh video gốc, tên có đuôi _catnhanh. Ví dụ video1.mp4 sẽ có thêm video1_catnhanh.mp4. Bấm phím bất kỳ để đóng cửa sổ đen.

Báo lỗi "python" hoặc "ffmpeg" không tìm thấy? Bạn chưa cài xong bước 2 hoặc chưa khởi động lại máy. Làm lại bước 2, khởi động lại máy rồi kéo thả lại. Vẫn lỗi thì chụp màn hình gửi vào nhóm Zalo để được hỗ trợ.
