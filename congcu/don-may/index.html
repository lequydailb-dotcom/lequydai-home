Bước ANhận file trong nhóm Zalo

  1. Vào nhóm Zalo ĐẠI LÊ AI

    Bấm nút Vào nhóm Zalo nhận file ở trang này, rồi bấm Tham gia nhóm. Nhóm miễn phí.

  2. Mở kho file của nhóm

    Trên máy tính (Zalo PC): trong nhóm, nhìn cột bên phải, mục Ảnh/Video, File, Link, bấm File.
    Trên điện thoại: trong nhóm, bấm biểu tượng ☰ ở góc trên bên phải, chọn Ảnh, file, link, rồi chọn thẻ File.
    File cũng được ghim ở đầu nhóm, bấm vào tin ghim là thấy.

  3. Tải file DonMay-DaiLeAI.zip

    Bấm vào file rồi chọn Tải về. Công cụ chạy trên máy tính Windows, nên hãy tải trên Zalo máy tính. Lỡ nhận trên điện thoại thì bấm giữ file, chọn Chia sẻ rồi gửi vào Cloud của tôi, sau đó mở Zalo trên máy tính để tải.

  4. Tìm file vừa tải

    File thường nằm trong thư mục Downloads (Tải xuống), hoặc thư mục Zalo Received Files trong Tài liệu (Documents).

Bước BMở và dùng DỌN MÁY

  1. Giải nén file

    Bấm chuột phải vào DonMay-DaiLeAI.zip, chọn Extract All (Giải nén tất cả), rồi bấm Extract. Bạn sẽ có thư mục DonMay-DaiLeAI.

  2. Bấm đúp vào DonMay.bat

    Nếu Windows hiện màn hình xanh "Windows protected your PC", bấm More info (Thông tin thêm) rồi Run anyway (Vẫn chạy). Đây là cảnh báo thường gặp với công cụ nhỏ chưa ký số.

  3. Bấm "1. QUÉT"

    Chương trình liệt kê từng nhóm rác và dung lượng có thể lấy lại.

  4. Bấm "2. DỌN NGAY"

    Đợi chạy xong là máy đã trống thêm. Muốn dọn cả tệp tạm của Windows, bấm nút Chạy bằng quyền quản trị trong chương trình rồi quét lại.

Mẹo: đóng trình duyệt, CapCut, Premiere trước khi dọn để dọn sạch hơn. Tệp nào đang được dùng sẽ được giữ lại, đó là bình thường. Chạy trên Windows 10 và 11, không cần cài thêm gì.

DỌN MÁY làm gì

  • Tệp tạm của bạn (Temp) và tệp tạm Windows (cần quyền quản trị)
  • Thùng rác
  • Bộ nhớ đệm Chrome, Edge, Cốc Cốc, Firefox
  • Bộ nhớ đệm CapCut và Premiere (tự tạo lại khi cần)
  • Ảnh thu nhỏ và báo cáo lỗi Windows

Không đụng tới

  • Tài liệu, ảnh, video của bạn
  • Dự án CapCut và Premiere
  • Mật khẩu, lịch sử đăng nhập, dấu trang trình duyệt
